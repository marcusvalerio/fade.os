# Manual do CORTEX.OS

O CORTEX é o sistema operacional da barbearia: agenda, atendimento, caixa,
comissão, estoque, clientes e financeiro num registro só. Este manual explica
como usar cada parte, do jeito que ela funciona hoje — nada aqui descreve
função que o produto ainda não tem.

Cada arquivo é um tema e pode virar uma página da central de ajuda. Os títulos
de nível 2 (`##`) são as perguntas que alguém faria no balcão.

## Como o CORTEX responde

Três sinais se repetem em todo o sistema e valem a pena conhecer:

- **O quadrado.** Cheio quer dizer "aconteceu" ou "está ativo" (confirmado,
  concluído, caixa aberto). Vazado quer dizer "ainda não" (agendado,
  aguardando contagem, caixa fechado). A cor diz o tipo — azul para
  andamento, verde para concluído, amarelo para atenção, vermelho para
  problema — e a palavra está sempre ao lado.
- **O quadrado girando.** Aparece dentro do botão enquanto o CORTEX está
  gravando. Não clique de novo: o botão fica travado até terminar.
- **O que o CORTEX já registrou.** Ao fechar um atendimento ou uma venda, a
  tela mostra, em sequência, cada lugar que recebeu o registro (caixa,
  financeiro, comissão, estoque, agenda, cliente). É o resultado real da
  operação, gravado de uma vez: ou tudo é registrado, ou nada é.
